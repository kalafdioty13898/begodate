# 🤖 بگودیت (Bagoodit)

ربات تلگرامی چت و آشنایی ناشناس، تمام‌فارسی، مخصوص افراد **۱۸ سال به بالا**.

> ⚠️ هویت واقعی هیچ کاربری (آیدی عددی تلگرام) هرگز به دیگران نشان داده نمی‌شود؛
> هر کاربر یک شناسه ناشناس می‌گیرد: دخترها `user5XXXX` و پسرها `user4XXXX`.

---

## ✨ امکانات

- **ثبت‌نام گام‌به‌گام:** جنسیت → سن (۱۸–۷۹) → استان (۳۱ استان) → شهر (همان استان) → اسم مستعار → عکس
- **منوی چت ناشناس:**
  - 🟢 چت تصادفی (رایگان)
  - 🔵 جست‌وجوی دختر / پسر (۱ سکه)
  - 🔴 افراد نزدیک (۳ سکه؛ اول هم‌شهری، بعد هم‌استانی)
  - 🟣 جست‌وجوی پیشرفته (۴ سکه؛ فیلتر سن + شهر)
- **صف انتظار هوشمند** با جلوگیری از race-condition و جلوگیری از تطبیق دوباره در بازه زمانی (قابل تنظیم)
- **جست‌وجوی کاربر** با شناسه (`user51234`) و درخواست چت با قبول/رد
- **چت ناشناس کامل:** متن، عکس، ویدیو، ویس، استیکر + پروفایل طرف + گزارش با ۷ دلیل + پایان چت
- **اقتصاد سکه‌ای:** تراکنش‌ها اتمیک و ثبت‌شده؛ پیام «🪙 سکه کافی نداری» در کمبود موجودی
- **معرفی دوستان:** لینک اختصاصی `t.me/Bot?start=refID`، پاداش فقط یک‌بار، بدون خودمعرفی
- **بازخورد:** پیام کاربر مستقیم به ادمین، پاسخ ادمین مستقیم به کاربر
- **پنل مدیریت کامل:** آمار، بن/رفع بن، تغییر سکه، مشاهده چت‌ها، صف، چت‌های فعال، گزارش‌ها، معرفی‌ها، پیام همگانی (با کنترل سیل + پیشرفت + توقف)، بازخوردها، کاربران تستی، تنظیمات زنده
- **سیستم کاربران تستی 🧪:** برای هر شهر ۲۰ حساب دختر + ۱۷ حساب پسر با آواتار گرافیکی تولیدشده
  (بدون عکس واقعی)، شفافیت کامل (برچسب «حساب تستی بگودیت»)، ۵۳۰+ پاسخ فارسی طبیعی در ۱۱ دسته
  با تشخیص هدف از روی کلیدواژه، بدون تکرار پشت‌سرهم، سقف ۶ تا ۱۰ پاسخ در هر چت، تأخیر طبیعی،
  ضدحلقه (پیام تستی هرگز دوباره وارد موتور پاسخ نمی‌شود)
- **تست‌مود ۷ روزه** (قابل تنظیم): انقضا در **هر تطبیق** بررسی می‌شود؛ ادمین می‌تواند روشن/خاموش/
  تمدید/حذف کند؛ اولویت کاربران واقعی (`REAL_USERS_FIRST=true`)
- **امنیت:** کوئری‌های پارامتری (ضد SQL Injection)، اعتبارسنجی callback، عدم اعتماد به آیدی در
  callbackها، کنترل نرخ پیام، هندلر سراسری خطا، لاگ بدون اطلاعات حساس، توکن فقط از متغیر محیطی

## 📂 ساختار پروژه

```
bagoodit/
├── bot.py                  # نقطه ورود
├── config.py               # تنظیمات (از .env)
├── database.py             # لایه دیتابیس (SQLite ماژولار؛ آماده مهاجرت به PostgreSQL)
├── locations.py            # ۳۱ استان + شهرها
├── seed_test_users.py      # ابزار ساخت کاربران تستی
├── requirements.txt
├── .env.example
├── .github/workflows/bot.yml
├── handlers/               # common، registration، main_menu، matching، chat،
│   │                       # search_user، feedback، admin
├── keyboards/              # همه دکمه‌ها و کیبوردها
├── services/               # matching، coins، settings، test_users، auto_reply، avatars
└── utils/                  # helpers (نرخ‌گذاری، کارت کاربر، ارسال امن)
```

## 🚀 راه‌اندازی محلی

```bash
cd bagoodit
pip install -r requirements.txt
cp .env.example .env      # مقدار BOT_TOKEN و ADMIN_ID را بگذار
python bot.py
```

ساخت کاربران تستی (اختیاری):

```bash
python seed_test_users.py          # اگر قبلاً ساخته شده‌اند کاری نمی‌کند
python seed_test_users.py --force  # بازسازی کامل
```

## 🤖 گرفتن توکن از BotFather

1. در تلگرام با [@BotFather](https://t.me/BotFather) گفت‌وگو کن.
2. `/newbot` → نام و یوزرنیم بده.
3. توکن را کپی کن و **فقط** در `.env` (محلی) یا GitHub Secrets بگذار — هرگز در کد یا گیت.
4. با [@userinfobot](https://t.me/userinfobot) آیدی عددی خودت را بگیر و در `ADMIN_ID` بگذار.

---

## 🔐 GitHub Secrets

در مخزن گیت‌هاب: `Settings → Secrets and variables → Actions`:

| Secret | مقدار |
|---|---|
| `BOT_TOKEN` | توکن BotFather |
| `ADMIN_ID` | آیدی عددی ادمین |

---

## ▶️ اجرا با GitHub Actions (رایگان، ولی دائمی نیست)

1. پروژه را به یک مخزن گیت‌هاب push کن (`.env` در `.gitignore` است و کامیت نمی‌شود).
2. دو Secret بالا را بساز.
3. تب **Actions** → «Run Bagoodit Bot» → **Run workflow**.
4. Job هر ۶ ساعت خودش دوباره بالا می‌آید؛ دیتابیس با cache بین اجراها حفظ می‌شود.

> ⚠️ **صادقانه بگویم:** GitHub Actions یک سرور دائمی نیست؛ بین اجراها چند ثانیه توقف رخ می‌دهد
> و گاهی cache می‌پرد. برای حرفه‌ای‌شدن، VPS بگیر (بخش بعدی).

## 🖥 مهاجرت به VPS (راه دائمی)

```bash
# روی سرور اوبونتو
git clone <repo> && cd bagoodit
pip3 install -r requirements.txt
nano .env                      # توکن و آیدی ادمین
python3 seed_test_users.py     # اختیاری
```

سرویس systemd تا ربات با ری‌بوت سرور دوباره بالا بیاید:

```ini
# /etc/systemd/system/bagoodit.service
[Unit]
Description=Bagoodit Telegram Bot
After=network-online.target

[Service]
WorkingDirectory=/root/bagoodit
ExecStart=/usr/bin/python3 bot.py
Restart=always
RestartSec=5
Environment=PYTHONUNBUFFERED=1

[Install]
WantedBy=multi-user.target
```

```bash
systemctl enable --now bagoodit
journalctl -u bagoodit -f      # مشاهده لاگ
```

مهاجرت به PostgreSQL در آینده: فقط `database.py` را با درایور psycopg بازنویسی کن؛
همه‌ی کوئری‌ها از همین لایه می‌گذرند.

## 🧪 مدیریت سیستم تستی

- پنل: `/admin` → **🧪 کاربران تستی**
- روشن/خاموش/تمدید ۷ روزه/ساخت/حذف کامل/ساخت آواتارها
- پیش‌فرضِ کد: `TEST_MODE_ENABLED=false` (تولید) — برای تست محلی در `.env` مقدار `true` بگذار
- انقضای تست‌مود **هر بار که تطبیقی رخ می‌دهد** بررسی می‌شود و پس از انقضا ادمین آگاه می‌شود
- حذف کاربران تستی فقط رکوردهای `is_test_user=true` را پاک می‌کند و چت‌های مرتبط را می‌بندد

## ⚙️ تنظیمات زنده (بدون ری‌استارت)

`/admin` → **⚙️ تنظیمات**: هزینه‌ها، پاداش معرفی، سکه خوش‌آمد، فاصله عدم تکرار تطبیق،
مدت تست‌مود، سقف پاسخ تستی، تأخیر پاسخ‌ها، اولویت کاربران واقعی.

## 🛡 نکات امنیتی

- توکن هرگز در کد یا لاگ نمی‌آید؛ فقط `.env` / Secrets.
- اگر توکن لو رفت: BotFather → `/revoke` و توکن جدید.
- `data/` و `.env` را هرگز کامیت نکن.
